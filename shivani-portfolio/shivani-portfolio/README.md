## 🚀 GitHub Upload Commands

### Step 1: Initialize Git (run once in project folder)
```bash
cd shivani-portfolio
git init
git add .
git commit -m "🚀 Initial commit: Shivani Dasari portfolio"
```

### Step 2: Create a new repository on GitHub
- Go to https://github.com/new
- Repository name: `shivani-portfolio` (or `ShivaniDasari156.github.io` for user page)
- Keep it **Public**
- Do NOT initialize with README (you already have one)
- Click **Create repository**

### Step 3: Push to GitHub
```bash
git remote add origin https://github.com/ShivaniDasari156/shivani-portfolio.git
git branch -M main
git push -u origin main
```

## 🌐 GitHub Pages Deployment Steps

### Option A: Deploy from Settings (Easiest)
1. Go to your repository on GitHub
2. Click **Settings** tab
3. Scroll to **Pages** section (left sidebar)
4. Under **Source**, select `main` branch, folder `/root`
5. Click **Save**
6. Wait ~2 minutes
7. Your site will be live at: `https://ShivaniDasari156.github.io/shivani-portfolio/`

### Option B: Create User Page (yourname.github.io)
1. Create a repo named exactly: `ShivaniDasari156.github.io`
2. Push your code to it
3. Site auto-deploys at: `https://ShivaniDasari156.github.io`
